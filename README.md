# Portafolio de Líder Salinas

Portafolio profesional de desarrollo Backend y Full Stack. Presenta proyectos reales,
experiencia, formación, stack técnico y canales de contacto.

## Stack

- Next.js 16 y React 19
- TypeScript
- CSS responsive sin framework de interfaz
- Metadata, sitemap y robots integrados con Next.js

## Desarrollo local

```bash
npm install
npm run dev
```

La aplicación estará disponible en `http://localhost:3000`.

## Validación

```bash
npm run lint
npm run build
```

## Publicación

El proyecto está preparado para desplegarse en Vercel desde la rama principal.
